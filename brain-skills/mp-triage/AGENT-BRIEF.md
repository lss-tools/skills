# Бриф исполнителю

Размести бриф внутри README «Постановка». Он синтезирует исходную заявку и решения в контракт работы, а не создаёт ещё одну спецификацию.

## Принципы

1. Описывай поведение и существенные контракты: сущности, типы, операции, конфигурацию, инварианты. Исполнитель прочитает свежий код перед изменением.
2. Не подменяй результат инструкцией «открой строку 42». Ссылки на проверенные источники полезны как доказательство, но текущий путь не должен быть единственным определением требования.
3. Дай самостоятельно проверяемые критерии. «Работает правильно» не определяет готовность.
4. Укажи исключения и границы. Для готового diff опиши оставшиеся пробелы, а не поручай построить уже существующую часть заново.

## Форма внутри постановки

```markdown
### Бриф исполнителю

**Категория:** дефект или улучшение.
**Суть:** одно предложение о требуемом изменении.
**Текущее поведение:** установленный результат и условия проверки.
**Требуемое поведение:** результат для пользователя, включая ошибки и исключения.
**Существенные контракты:** операции, типы, конфигурация и инварианты.
**Проверка результата:** наблюдаемые критерии готовности.
**Вне границ:** соседние изменения, которые сюда не входят.
```

## Пример дефекта

Описание обрывается посреди слова при превышении лимита 1024 символа. Требуется обрезать его по последней границе слова и добавить `...`, сохранив общий лимит. Критерии: короткое описание сохраняется; длинное обрезается по слову; итог содержит многоточие и не превышает лимит. Изменение самого лимита и поддержка многострочного описания вне границ.

## Пример существующей правки

Diff уже добавил `--json` для списка. Успешный ответ сериализуется, но ошибки остаются обычным текстом. Бриф поручает завершить контракт: успешный результат и ошибка представляют корректный JSON, коды завершения сохраняются, обычный режим не меняется. Исполнитель использует имеющуюся сериализацию, а не создаёт вторую.

Плохой бриф: «Исправь triage в главном файле около строки 150». Он не задаёт наблюдаемого результата, критериев или границ.

# Явная внешняя передача

Применяй, когда пользователь явно запросил перенос контекста вне обычного маршрута Brain. Для обычного продолжения актуализируй законное состояние задачи штатным процессом: README и `next_action` остаются источниками состояния.

## Собрать минимальную передачу

1. Выдели цель следующего сеанса из запроса. Если она задана, подстрой отбор сведений под неё.
2. Найди действующие постановку, план, решения, исследование и фактическое состояние кода. Давай путь или URL вместо копирования содержимого.
3. Отдели завершённое с доказательствами, незавершённое и неизвестное. Укажи текущую базу или ветку только если проверил её.
4. Добавь сведения из разговора, которых ещё нет в артефактах и без которых получатель потеряет решение или ограничение.
5. Удали секреты и лишние персональные данные. Секрет передаётся через принятый защищённый механизм, а не текст экспорта.

## Формат

```text
Цель следующего сеанса: ...
Задача и старт: путь к README, номер и маршрут start_task.py
Состояние: что проверено; ссылка на результат
Следующее действие: одно конкретное действие и критерий завершения
Ограничения и открытое: только необходимое получателю
Указатели: постановка, plan.md, решения, diff или commit
Рекомендуемые скилы: точное имя; зачем читать; канонический путь
```

Имена скилов проверяй по маршруту задачи или `skill_index.py`. Получатель читает указанный `SKILL.md`; передача не предполагает отдельного инструмента вызова скилов. Существующие разрешения и защищённые границы передай явно, без их расширения.

По умолчанию выдай сообщение. Если нужен файл, сохрани временный экспорт в `D:/Brain/temp` с уникальным именем и передай кликабельную ссылку. Не добавляй постоянный `handoff.md` рядом с README и не заводи вторую историю прогресса.

Готово, когда свежий агент понимает цель, находит канон и может начать следующее действие без чтения всей беседы. Экспорт не подменяет актуальные документы задачи.

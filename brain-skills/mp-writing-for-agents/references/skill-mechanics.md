# Механика скила в Brain

Это ветвь справки для инструкции в форме скила. Общие приёмы указателей, иерархии и завершения находятся в [SKILL.md](../SKILL.md).

## Имя и описание

`name` совпадает с каталогом. Описание по каноническому правилу Brain состоит из пяти частей в одном абзаце до 700 символов:

1. Назначение с действием и объектом.
2. Вход, который нужен до вызова.
3. Наблюдаемый выход.
4. Граница с названным ближайшим скилом; при отсутствии соседа укажи это прямо.
5. Когда не применять.

Называй режим, если он меняет результат: частичная загрузка, только чтение, пропуск проверки. Русское описание выбирает скил под русскую задачу. Агрегат называет атомарные скилы и явно передаёт им работу; сам он нужен для выбора.

## Обнаружение и явный вызов

Upstream различает автономный выбор моделью и вызов человеком, сопоставляя цену постоянного описания и необходимость помнить имя. В Brain дополнительно различаются резидентный и адресуемый скил. Резидентность определяет действующая матрица, адресную доставку определяет маршрут задачи; этот текст не переключает их.

Новый скил из адаптированного набора остаётся адресуемым. Отсутствие `disable-model-invocation` в каноне не означает разрешения сделать его резидентным. Не переносить предположение upstream, что другой скил обязательно виден отдельному инструменту вызова.

Для зависимости укажи условие чтения и путь к её `SKILL.md`. Внутри источника используй существующий относительный путь. Для другого источника разрешай точное имя через маршрут задачи или индекс и читай напечатанный канон. Похожий первый результат поиска не доказывает наличие нужного имени.

Общую справку держи в одном месте, которое доступно всем потребителям. Выноси отдельный скил, когда у него есть самостоятельное условие выбора или реальный потребитель. Не выделяй каждую маленькую справку ради упаковки.

## Агрегат выбора

Когда человеку трудно помнить много явных команд, агрегат показывает имена и условия выбора. Он не подменяет исполнителей. Пример: «для готовой постановки используй mp-to-tickets; для невыясненных развилок используй mp-wayfinder». Зависимости остаются явными, выходы исполнителей не дублируются внутри агрегата.

## Канон и результат сборки

Найди канон через индекс и источник. Сначала меняй разрешённый канон, затем запускай установленную сборку при наличии такой части поручения. Сгенерированные `.agents/skills`, `.claude/skills` и AGENTS.md не являются местом самостоятельной правки. Ссылки проверь после подключения всех зависимостей.

Правило описания, маршрутизация и разрешения остаются в карточках Brain. Этот reference показывает применение, а не вводит новую политику.

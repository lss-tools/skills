# Уточнение с записью в документы

Этот агрегат выбирает связку методов. Самостоятельного третьего интервью или отдельного документа он не вводит.

1. Прочитай [mp-grilling](../mp-grilling/SKILL.md): он ведёт дерево зависимых решений, находит фронт и задаёт один доступный вопрос.
2. Прочитай [mp-domain-modeling](../mp-domain-modeling/SKILL.md): он уточняет предметные термины, проверяет сценарии и противоречия с кодом.
3. Применяй оба метода совместно. Проверяй факты самостоятельно до вопросов; при ответе сразу уточняй термин или фиксируй решение. Не запускай два дублирующих опроса.
4. Сохраняй определения и пользовательские сценарии в README «Постановка», выборы в «Решения», открытые вопросы в «Неизвестное». Не создавай отдельный словарь, ADR или трекер.

```text
mp-grilling: доступный вопрос → ответ → новый фронт
                             ↓
mp-domain-modeling: термин → сценарий → запись в README
```

Готовность проверяй по обоим атомарным скилам: ветви разобраны, термины различимы, противоречия разрешены либо явно открыты. Уже принятые решения и разрешённую работу повторно не согласовывай. Для задачи 1С связка дополняет действующую стадию, не заменяя её.
